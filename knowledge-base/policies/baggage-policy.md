# SkyWay Airlines Baggage Policy

## Overview

SkyWay Airlines provides comprehensive baggage services to ensure your belongings travel safely with you.

## Carry-On Baggage

### Allowances

- **Personal Item**: 1 per passenger (free)
  - Maximum size: 18" x 14" x 8"
  - Examples: purse, laptop bag, small backpack

- **Carry-On Bag**: 1 per passenger
  - Maximum size: 22" x 14" x 9"
  - Maximum weight: 22 lbs (10 kg)
  - Fee varies by ticket type (see below)

### Carry-On Fees by Ticket Type

| Ticket Type     | Carry-On Fee |
| --------------- | ------------ |
| Basic Economy   | $35          |
| Main Cabin      | Included     |
| Premium Economy | Included     |
| Business Class  | Included     |
| First Class     | Included     |

## Checked Baggage

### Standard Allowances

| Ticket Type     | Free Bags | Additional Bag Fee    |
| --------------- | --------- | --------------------- |
| Basic Economy   | 0         | $30 first, $40 second |
| Main Cabin      | 1         | $40 each              |
| Premium Economy | 2         | $40 each              |
| Business Class  | 2         | Free                  |
| First Class     | 3         | Free                  |

### Size and Weight Limits

- **Standard Bag**: Up to 50 lbs (23 kg), 62 linear inches
- **Overweight Bag** (51-70 lbs): Additional $100
- **Oversized Bag** (63-80 linear inches): Additional $150
- **Maximum**: 70 lbs (32 kg), 80 linear inches

## Delayed Baggage

### Compensation

If your baggage is delayed, SkyWay Airlines provides:

- **Essential Items Reimbursement**: Up to $50 per day
- **Maximum Reimbursement**: $200 total
- **Eligible Items**: Toiletries, underwear, essential clothing

### Reporting Delayed Baggage

1. Report immediately at the baggage service counter
2. Obtain a Property Irregularity Report (PIR) number
3. Keep all receipts for reimbursement claims
4. File claim within 21 days of receiving baggage

## Lost Baggage

### Definition

Baggage is considered lost if not located within 21 days of the delayed baggage report.

### Compensation

- **Domestic Flights**: Up to $3,800 per passenger
- **International Flights**: Up to approximately $1,780 (based on Montreal Convention)

### Required Documentation

- Original baggage claim ticket
- Property Irregularity Report (PIR)
- Itemized list of contents with values
- Proof of purchase for high-value items

## Damaged Baggage

### Reporting

- Report damage before leaving the airport
- Obtain a damage report from baggage services
- Take photos of the damage

### Compensation

- Repair or replacement of damaged bag
- Compensation for damaged contents (with documentation)
- Claims must be filed within 7 days

### Exclusions

Damage not covered:

- Normal wear and tear
- Overpacked bags
- Fragile items not properly protected
- Items prohibited in checked baggage

## Special Items

| Item           | Fee           |
| -------------- | ------------- |
| Golf Clubs     | $35 each way  |
| Skis/Snowboard | $35 each way  |
| Surfboard      | $100 each way |

### Musical Instruments

- Small instruments: Carry-on (if fits in overhead bin)
- Large instruments: Purchase additional seat
- Fragile instruments: Special handling available

### Mobility Devices

- Wheelchairs: Free
- Walkers: Free
- Scooters: Free (battery restrictions apply)

## Prohibited Items

### Not Allowed in Carry-On or Checked Bags

- Explosives and fireworks
- Flammable items
- Toxic substances
- Compressed gases

### Not Allowed in Checked Bags

- Lithium batteries (spare)
- E-cigarettes
- Cash and jewelry (recommended carry-on)
- Medication (recommended carry-on)
